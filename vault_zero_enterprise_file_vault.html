Architecture & 100% Free GitHub Hosting Guide

✓ HOW THIS WORKS RIGHT NOW

This app converts your Username into a cryptographic credential behind the scenes so you never need an email address. Your files are split into binary chunks and synced to the cloud database automatically.

Step 1: Host on GitHub Pages for 100% Free

  1. Create a free account at github.com and create a new Public Repository (e.g., my-vault).
  2. Save this entire single file as index.html and upload it to your repository.
  3. Go to your repository Settings → Pages.
  4. Under "Branch", select main and click Save.
  5. Within 60 seconds, your vault will be live at https://yourname.github.io/my-vault/ accessible on any mobile phone!

Step 2: Optional 1GB Free Storage Upgrade (Supabase)

By default, this app stores files directly inside the built-in Cloud Document Vault (optimized for scripts, documents, archives, and images up to ~750KB per file). If you want to upload massive video or archive files up to 1GB for 100% free (no credit card needed):

  1. Create a free project at supabase.com (Free tier gives 1GB File Storage + 500MB Database).
  2. Go to Storage in Supabase and create a Public Bucket named vault.
  3. Click the Engine: Cloud Vault button in the top bar of this app and paste your Project URL & Anon Key.
